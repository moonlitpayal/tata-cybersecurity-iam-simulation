## Task 2: IAM Strategy Assessment

**What I was asked to do:** Learn how to judge whether an organisation is ready for IAM and what to consider when adopting it in different settings. Assess hypothetical company scenarios for IAM readiness, then develop a checklist for evaluating IAM strategy and readiness.

**What I did / my answer:**
- Studied how to evaluate an IAM strategy (goal alignment, user lifecycle, access controls, compliance, integration) and how to tailor it to an organisation (size, industry, user types, legacy systems, cloud, user experience).
- Completed the knowledge check and got **both questions correct**.
- Read the briefing email from Ravi (IAM business analyst) about TechCorp: a global IT company in 100+ countries with 150,000+ employees, worried about breaches, wanting a smoother user experience and less manual work.
- Wrote a reply email to Ravi summarising the key considerations and a 7-part IAM readiness checklist (my submission is below).

**Subject:** TechCorp IAM Strategy Assessment – Key Considerations and Checklist

Hi Ravi,

Thank you for sharing the briefing on TechCorp. After reviewing the information, I've outlined key considerations and a structured checklist to guide our assessment of TechCorp's IAM readiness.

**Key Considerations:**
TechCorp's global scale, large workforce, and ongoing digital transformation make IAM essential for safeguarding its assets and ensuring seamless access. Our assessment should confirm that the IAM framework:
- Strengthens data security across all platforms and repositories.
- Provides a seamless yet secure user experience for employees, partners, and customers.
- Integrates effectively with existing systems and cloud platforms.
- Complies with global data privacy and cybersecurity standards.
- Supports automation to enhance operational efficiency and reduce manual effort.

**IAM Strategy Assessment Checklist:**

1. **User Lifecycle Management**
   - Review user onboarding and offboarding processes.
   - Evaluate automation in provisioning/deprovisioning.
   - Assess role-based access control (RBAC) and identity federation practices.

2. **Access Control Mechanisms**
   - Assess authentication methods (MFA, SSO, password policies).
   - Review access review and recertification frequency.
   - Evaluate privileged access management (PAM) controls.

3. **Compliance and Governance**
   - Verify alignment with regulatory standards (e.g., ISO 27001, GDPR).
   - Check audit trails, reporting, and monitoring capabilities.
   - Evaluate policy enforcement and incident response mechanisms.

4. **Integration with Existing Systems**
   - Identify IAM integration points with HR systems, directories (AD/LDAP), and apps.
   - Review data synchronization and identity consistency across systems.
   - Assess interoperability between IAM and enterprise platforms.

5. **Cloud Services Integration**
   - Review IAM compatibility with hybrid and multi-cloud environments.
   - Evaluate usage of cloud identity providers (Azure AD, AWS IAM, etc.).
   - Check secure access management for APIs and service accounts.

6. **Enhanced User Experience**
   - Assess SSO implementation for ease of access.
   - Evaluate self-service options for password resets and access requests.
   - Measure user satisfaction and login performance.

7. **Operational Efficiency and Future-readiness**
   - Evaluate scalability, automation capabilities, and policy standardization.
   - Identify gaps in global IAM practices.
   - Recommend IAM maturity enhancements aligned with TechCorp's transformation goals.

These steps will help us comprehensively assess TechCorp's IAM readiness, identify gaps, and provide actionable recommendations to strengthen their overall identity and access management strategy.

Best regards,
Payal Mehta

## Task 3: Crafting Custom IAM Solutions

**What I did / my answer:**
